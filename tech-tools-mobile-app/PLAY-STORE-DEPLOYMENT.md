# TechTools Mobile App - Play Store Deployment Guide

## Prerequisites

1. **Google Play Developer Account** ($25 one-time fee)

   - Sign up at: https://play.google.com/console/signup

2. **Expo Account** (free)

   - Sign up at: https://expo.dev/signup

3. **EAS CLI Installed**
   ```bash
   npm install -g eas-cli
   ```

## Step 1: Login to Expo & Configure Project

```bash
cd tech-tools-mobile-app

# Login to Expo
eas login

# Initialize EAS for this project (links to your Expo account)
eas build:configure
```

This will:

- Create/update your project on Expo servers
- Generate a unique project ID
- Update `app.json` with the project ID

## Step 2: Update App Configuration

Edit `app.json` and replace placeholder values:

```json
{
  "expo": {
    "owner": "YOUR_EXPO_USERNAME",
    "extra": {
      "eas": {
        "projectId": "YOUR_PROJECT_ID" // Generated by eas build:configure
      }
    },
    "updates": {
      "url": "https://u.expo.dev/YOUR_PROJECT_ID"
    }
  }
}
```

## Step 3: Build for Play Store

### Option A: Build on Expo Cloud (Recommended)

```bash
# Build production AAB (Android App Bundle)
npm run build:prod
# Or directly:
eas build --profile production --platform android
```

This builds on Expo's servers and:

- Generates signing keys automatically (stored securely by Expo)
- Creates an `.aab` file for Play Store
- Takes 10-20 minutes

### Option B: Build Locally

```bash
# Requires Android SDK and Java
npm run build:local
```

## Step 4: Download the Build

After build completes:

1. Go to https://expo.dev/accounts/YOUR_USERNAME/projects/techtools/builds
2. Download the `.aab` file

Or via CLI:

```bash
eas build:list
# Copy the build URL and download
```

## Step 5: Create Google Play Console App

1. Go to [Google Play Console](https://play.google.com/console)
2. Click **"Create app"**
3. Fill in:
   - App name: **TechTools**
   - Default language: **English (United States)**
   - App or game: **App**
   - Free or paid: **Free** (or Paid)
4. Accept policies

Navigate to **"Main store listing"** and fill in:

- **App name**: TechTools - Tech Accessories Store
- **Short description** (80 chars): Shop premium tech accessories with fast delivery and great prices.

### Graphics Assets Required

- **App icon**: 512x512 PNG (use assets/images/icon.png)
- **Feature graphic**: 1024x500 PNG
- **Screenshots**: At least 2-8 phone screenshots
  - Recommended: 1080x1920 or 1080x2340 pixels

### Take Screenshots

1. Home screen with flash deals

## Step 7: App Content & Policies

### Privacy Policy (Required)

Host a privacy policy at your domain, e.g.:
`https://nexusai.lt/privacy-policy`

### Content Rating

Complete the content rating questionnaire - your app is likely **"Everyone"**

### Data Safety

Declare what data your app collects:

- Email address (for login)
- Purchase history (for orders)
- Device identifiers (for analytics)

## Step 8: Upload the AAB File

1. Go to **"Production"** → **"Create new release"**
2. Click **"Upload"** and select your `.aab` file
3. Add release notes:

   ```
   Initial release of TechTools mobile app.

   Features:
   - Browse and search products
   - Add items to cart and wishlist
   - Secure checkout
   - Order tracking
   - User account management
   ```

4. Click **"Review release"**

## Step 9: Submit for Review

1. Complete all required sections (check sidebar for red ❌ marks)
2. Click **"Start rollout to Production"**
3. Wait for Google's review (typically 1-7 days for new apps)

## Automated Submission (Optional)

### Set up Google Service Account

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Create a new project or select existing
3. Enable **Google Play Android Developer API**
4. Create a Service Account with **"Service Account User"** role
5. Download JSON key as `google-service-account.json`
6. In Play Console, go to **Users & Permissions** → **Invite new users**
7. Add service account email with **"Release manager"** permission

### Submit via EAS

```bash
# Place google-service-account.json in project root
npm run submit:android
```

## Troubleshooting

### Build Failed

```bash
# Check build logs
eas build:list
# Click on failed build for detailed logs
```

### Signing Key Issues

```bash
# View current credentials
eas credentials --platform android

# Reset and create new keystore
eas credentials --platform android
# Select: Keystore → Regenerate
```

### App Rejected

Common reasons:

1. Missing privacy policy
2. Misleading app description
3. Broken functionality
4. Inappropriate content
5. Missing required permissions
